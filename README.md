# Puzzle 15

Juego Puzzle Deslizante (15-Puzzle) construido con Qt6 y DTK6.

## Compilación

```bash
mkdir build && cd build
cmake ..
make
```

## Ejecución

```bash
./puzzle
```

## Controles

- Haz clic en una pieza adyacente al espacio vacío para desplazarla.
- El objetivo es ordenar los números del 1 al 15 en secuencia.
- El menú Juego permite crear un nuevo juego o cambiar el tamaño del tablero (3x3 o 4x4).
